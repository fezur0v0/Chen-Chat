# 便签式日记

新建和编辑沿用纸质页面，顶部复用公共返回按钮和顶部模糊层，使用 Lucide Undo2、Redo2 和 Check 图标（原始路径来自 lucide-icons/lucide，与 React Icons 的 Lu 系列同源）。详情页只显示编辑入口。

标题旁显示所选心情；未选择时使用 assets/diary-unset-mood.svg 的蜡笔圆圈问号。点击打开心情选择弹窗，自定义绘制沿用原有画板。底部工具分别添加照片、调整字号、打开更多操作（取消／删除）。未保存退出需要确认。

每篇最多 6 张经过压缩和来源校验的本地照片；照片保存为 data URL，包含在 JSON／ZIP 备份的日记记录中，可能增加本机存储占用。字体大小支持 16／18／20；旧日记默认 16，不选照片时不添加额外数据字段。保存失败保留草稿。撤销重做覆盖标题、内容、日期、心情选择、图片与字号，本次编辑最多保留 100 个历史状态，退出后清除，不跨日记共享。

浏览器模拟检查覆盖新建、详情、编辑、取消、保存、心情选择／绘制、图片、字号、备份重载、存储失败恢复及窄屏／深色／横屏／短视口；APK 和实际系统键盘仍需实机确认。
