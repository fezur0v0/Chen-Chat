# 便签式富文本日记

底部工具为 Aa、列表、引用、装饰分隔符（正文为虚线、小爱心与圆点）、图片，统一使用 Lucide 图标。点击 Aa 会取消正文焦点以收起输入法，并在底部展开文字面板；面板内操作保留编辑器选区，不重新聚焦正文。支持加粗、斜体、下划线、删除线、高亮、16／18／20／24／36／48／64／72 字号和固定色板；颜色可恢复默认。移除 H2／H3 入口和字数显示，已有标题格式继续兼容显示。顶部不显示“写日记”文字，复用公共返回箭头、撤销／重做／保存及模糊层。删除日记仍在详情页底部。中间是独立滚动的完整编辑区，底栏在文档流中固定占位，不覆盖正文或系统安全区。

编辑器是本地打包的 Tiptap，不加载 CDN、不请求付费服务。正文同时保存可搜索的纯文字 content 和受限 JSON richText；白名单只允许文字、基础段落和格式，不渲染导入的 HTML／脚本／媒体／链接／任意属性。旧日记保持纯文字。粘贴采用纯文字，单篇仍限制 12000 字。修改纯文字导致与文档不匹配时丢弃过期格式。撤销重做覆盖本次编辑的文档、标题、日期、心情与图片，最多 100 个状态；退出清除，保存失败保留草稿。

图片仍最多 6 张本地压缩照片；按 AIRP 参考样式在正文底部独立显示三格缩略图，超过三张时第三格标出剩余数量。点击展开全部图片，编辑时可移除；不把图片插进正文。照片随 JSON／ZIP 备份恢复。旧记录的字号会保留，当前排版通过富文本工具处理。

顶部、正文、底部与文字面板共用一张纸的底色和连续纹理；自己为粉色、AI 为蓝色，并适配深色模式。未选心情显示同色系透明底蜡笔圆圈问号，颗粒和边缘位移已细化；噪点只作用于笔画，不能合成整块底色。心情选择弹窗居中，单行横滑、隐藏滚动条，New 位于下方。自定义绘制使用独立画布布局：顶部返回／保存，下方名称、圆形画布和工具；取消不影响日记草稿。

## 编辑器构建

正常运行和 APK 同步只需要现成的 src/vendor/tiptap.js；无需安装编辑器依赖。需要重建时进入 scripts/vendor-editor，运行 npm ci --ignore-scripts，再运行 node build.mjs。锁定版本的依赖只安装在该目录，不修改 App 根 package.json。MIT 许可与版本见 src/vendor/editor-LICENSES.txt；不要删除许可证文件。

验证：格式保存／恢复、文字安全转义、非法属性与媒体过滤、文档深度／字数／节点上限、旧数据兼容；浏览器覆盖各格式工具、撤销重做、心情弹窗／绘制、照片区／图库、保存失败／取消、窄屏／横屏／深色／短视口。APK 与系统软键盘仍需实机确认。

字体样式的 JSON 仅允许 textStyle 的预定义字号与色板，以及固定高亮色；HTML 渲染前逐属性校验，拒绝任意 CSS／URL。旧段落、列表、标题与引用结构仍然兼容。原生软键盘是否完全收起需 APK 实机确认；浏览器已验证取消焦点及鼠标／触屏选区保留。
